Harini Venkatesan Data Analyst Portfolio

## Overview
This is my personal professional portfolio, designed to showcase my skills, projects, and educational background in data analysis and business computing.

The portfolio is a static single-page application built using HTML and styled with **Tailwind CSS** for a clean, modern, and fully responsive design.

## Key Features
* **Data Analysis Focus:** Clearly highlights core competencies in Python, Power BI, SQL, and Data Visualization.
* **Skill Proficiency:** Utilizes custom progress bars to visually represent technical proficiency levels.
* **Interactive Contact:** Includes a direct contact form (using Formspree) and direct links to LinkedIn, GitHub, WhatsApp, and Instagram.
* **Project Showcase:** Features three key projects demonstrating practical application of data tools, including EDA and Machine Learning (K-Means Clustering).

---

## Technology Stack
* **HTML5:** Structure and content organization.
* **Tailwind CSS (CDN):** Utility-first framework for rapid, responsive styling.
* **Font Awesome (CDN):** Used for all social media and contact icons.
